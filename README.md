# 우리 반 모형 시계

초등학교 1학년 교실(TV·전자칠판)에서 시각 읽기를 익히는 아날로그 모형 시계 웹앱입니다.

👉 https://jihye84.github.io/clock/

## 기능

- **시침·분침 드래그**: 바늘을 손가락이나 마우스로 잡고 돌립니다. 시계방향, 반시계방향 모두 됩니다.
  - 시침을 숫자 한 칸 돌리면 분침이 함께 한 바퀴 돌아요.
  - 분침을 돌리면 시침도 조금씩 따라 움직여요.
- **시각 상자**: 지금 시계가 가리키는 시각을 "7시 18분"처럼 보여 줍니다(시는 빨강, 분은 파랑). 끌 수 있습니다.
- **5분 단위 숫자**: 시계 바깥에 5, 10, 15 … 60을 보여 줍니다. 켜고 끌 수 있습니다.
- **현재 시각 모드**: 실제 시각대로 바늘이 움직입니다. 이 모드에서는 드래그가 잠겨요.
  - 이 모드를 켰을 때만 **초침 보이기** 스위치가 나타납니다. 손으로 돌리는 기본 모드에서는 초침이 헷갈리지 않도록 늘 숨겨요.
- **12시로 맞추기** 버튼
- 설정판 맨 아래의 **시계 읽기 연습**, **알맞은 시계 찾기** 칸을 누르면 각 화면으로 갑니다. 각 화면 왼쪽 위의 작은 시계 버튼으로 돌아와요.
- 화면 크기에 맞춰 스크롤 없이 표시됩니다. 가로로 넓은 화면에서는 설정이 왼쪽에 펼쳐지고, 좁은 화면에서는 오른쪽 위 버튼으로 엽니다.
- 우클릭·길게 누르기 메뉴·글자 선택을 막았습니다.
- 카카오톡·네이버·페이스북 등 앱 안의 브라우저에서 열면 크롬·사파리로 다시 열리도록 했습니다(아이폰은 안내 화면).

## 시계 읽기 연습 (`practice.html`)

👉 https://jihye84.github.io/clock/practice.html

- **다음 문제**를 누를 때마다 '몇 시' 또는 '몇 시 30분' 시계가 새로 나옵니다(바로 앞 문제와 같은 시각은 나오지 않아요).
- **정답**을 누르면 시계 아래에 "7시 30분" 같은 시각 상자가 나타납니다.
- 위쪽에서 문제 종류를 **섞어서 / 30분만 / 정각만**으로 고를 수 있어요.
- 문제가 바뀔 때 분침은 늘 한 바퀴 더 돌고 제자리를 찾아가요.
- **바늘 바꾸기**를 켜면 문제마다 바늘 모양(막대·화살표·잎사귀·동그라미·삼각형 뿔·빅벤풍 고전 바늘·고리 바늘)과 색이 바뀌어요. 실제 시계처럼 두 바늘이 모두 검은색인 경우도 나와요. 시침은 늘 짧고 굵게, 분침은 길고 가늘게 그리고, 정답 상자의 글자색도 바늘 색을 따라가요.
- 두 버튼은 전자칠판에서 오른쪽 아래에 있습니다.
- 키보드: **스페이스** 다음 문제, **엔터** 정답, **탭** 섞어서 → 30분만 → 정각만(Shift+탭은 거꾸로), **B** 바늘 바꾸기 켜기/끄기. 한글 입력 상태에서도 B가 됩니다. 발표용 리모컨의 → 버튼으로도 다음 문제로 넘어가요.

## 알맞은 시계 찾기 (`choose.html`)

👉 https://jihye84.github.io/clock/choose.html

- 위에 "12시 30분" 같은 목표 시각이 나오고, 아래 시계 4개 중 맞는 것을 고릅니다. 문제는 끝없이 새로 만들어져요.
- 틀린 보기는 아이들이 자주 헷갈리는 모양으로 만들어요: 한 시간 앞·뒤 시각(12시 30분 ↔ 1시 30분), 30분인데 짧은바늘이 숫자를 정확히 가리키는 시계, 두 바늘 자리가 뒤바뀐 시계, 두 바늘이 모두 긴바늘인 시계, 정각과 30분이 바뀐 시계. 네 시계는 늘 서로 다른 모양이에요.
- 틀리면 그 시계에 ✕가 생기고 다시 고를 수 있어요. 맞히면 초록 테두리와 ✓가 나오고, 위에 "맞힘 (처음에 맞힌 수) / (푼 문제 수)"가 쌓여요.
- **섞어서 / 30분만 / 정각만**을 고를 수 있어요.
- 키보드: **1~4** 보기 고르기, **스페이스** 다음 문제, **탭** 문제 종류 바꾸기.
